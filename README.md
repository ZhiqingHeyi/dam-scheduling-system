# 🏗️ 拱坝动态排仓系统 Web版 v2.0

基于原MATLAB系统的完整Web重构，采用蓝色科技大屏风格设计。

## ✨ 系统特性

### 核心功能
- ✅ **数据库连接管理** - 支持MySQL数据库配置与测试
- ✅ **多目标智能排仓** - AHP层次分析法 + 熵权法组合决策
- ✅ **前沿驱动排序算法** - 三级约束漏斗（L1严格/L2放宽/L3兜底）
- ✅ **缆机资源调度** - 动态排班与容量优化
- ✅ **冬歇期自动处理** - 智能避开施工禁期（11/1-4/10）
- ✅ **工期压缩算法** - 二次压缩满足截止日期要求
- ✅ **实时可视化** - ECharts动态渲染坝段浇筑顺序图
- ✅ **WebSocket日志** - 实时推送计算进度与状态
- ✅ **文件管理** - 多格式导出与下载（Excel/PNG）

## 🚀 快速开始

### 环境要求
- Python 3.9+
- Node.js 16+
- MySQL 5.7+ (或 MariaDB)

### 安装步骤

1. **克隆或解压项目**
```bash
cd dam-scheduling-system
```

2. **启动服务** (Windows)
双击 `start.bat` 或在命令行运行：
```bash
start.bat
```

3. **手动启动** (可选)

**启动后端：**
```bash
cd backend
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
uvicorn main:app --host 0.0.0.0 --port 8000 --reload
```

**启动前端：**
```bash
cd frontend
npm install
npm run dev
```

4. **访问系统**
- 前端界面: http://localhost:3000
- API文档: http://localhost:8000/docs
- 后端健康检查: http://localhost:8000/health

## 🔧 核心算法说明

### 1. 权重计算体系
- **AHP主观权重** - 专家判断矩阵几何平均合成，一致性检验 CR<0.1
- **熵权法客观权重** - 基于数据离散程度的信息熵计算
- **组合权重** - α×AHP + (1-α)×Entropy，默认 α=0.5

### 2. 前沿选择排序算法
**三级漏斗筛选机制**:
- **L1 (严格模式)**: 相邻高差≤6m 且 全坝高差≤12m → 直接选择最优得分
- **L2 (放宽模式)**: 相邻高差≤9m 且 全坝高差≤13m → 允许适度超限
- **L3 (兜底策略)**: 综合代价最小化（含回拉奖励机制）

**阶段感知策略**:
- B1混排阶段：优先B1仓面，保护B2过渡带完整性
- B2过渡阶段：原始顺序邻近窗口柔性回归，尾部收口优先处理难仓面

### 3. 缆机资源调度
- 日最大容量：4台缆机
- 同坝段间歇窗口：7-20天（可配置）
- 双模式支持：正常模式 / 压缩模式

### 4. 冬歇期处理
- 自动避开：每年11月1日 ~ 次年4月10日
- 保持相对顺序不变，整体后移至冬歇结束次日

### 5. 工期压缩（可选）
- 固定锚点：A段已完成 + B段第一组
- 开放日历轴：去除冬歇期的连续施工轴
- 逐空白日前移：贪心式压缩策略

## 🛠️ API接口文档

### 数据库管理
- `POST /api/database/test-connection` - 测试数据库连接
- `GET /api/database/config` - 获取当前配置
- `POST /api/database/save-config` - 保存配置

### 排仓调度
- `POST /api/scheduling/run` - 执行排仓计算
- `GET /api/scheduling/status` - 获取系统状态

### 文件管理
- `POST /api/files/upload` - 上传数据文件
- `GET /api/files/download/{filename}` - 下载文件
- `GET /api/files/output-files` - 获取输出文件列表
- `GET /api/files/preview/{filename}` - 预览文件内容

### WebSocket
- `WS /ws/logs` - 实时日志推送

## ⚙️ 高级配置

可通过修改 `backend/config.py` 调整参数：

```python
SCHEDULING_ALPHA = 0.5          # 主客观权重比例
MAX_CRANE_PER_DAY = 4          # 每日最大缆机数
MIN_GAP_DAYS = 7               # 最小间隔天数
MAX_GAP_DAYS = 20              # 最大间隔天数
N_EXTRA = 20                   # B2过渡段抽取数量
WINTER_START_MONTH = 11        # 冬歇开始月份
WINTER_END_MONTH = 4           # 冬歇结束月份
```

## 🎯 使用流程

1. **配置数据库** → 填写MySQL连接信息并测试
2. **上传数据** → 上载 BaselineSchedule.xlsx、ActualDone.xlsx 等
3. **设置参数** → 选择开始日期、是否启用压缩等
4. **执行排仓** → 点击"生成排仓"按钮
5. **查看结果** → 实时查看日志、结果摘要和可视化图表
6. **导出文件** → 下载生成的Excel报表和PNG图表

## 📝 注意事项

1. 首次运行需安装依赖：`pip install -r backend/requirements.txt`
2. 确保MySQL服务已启动且端口可访问
3. 大规模数据集计算可能需要30秒-2分钟
4. 建议使用Chrome/Edge浏览器以获得最佳体验
5. 支持1920x1080及以上分辨率的大屏显示
